STUDY / SOURCE-FIXED WORKING MEMORY / v1

Reread the same source.
Structure the working state.

With source material fixed by privileged selection, ordinary rereading and a structured working state started from the same first answer. Fresh 12-query results and deliberately selected known 8-query regressions are reported separately.

2026-10-24 · Saved actual AI outputs. Browsing does not run an AI.

01 / PRIMARY COMPARISON

Use ordinary rereading as the primary comparator.

No additional improvement in answer outcomes from structuring was observed on this sample.

All fresh 12 queries were already correct at the shared first answer: 6/6 complete supported answers and 6/6 correct abstentions, leaving no headroom on this sample.

In the deliberately selected known eight-query set, 3 partial supported answers remained in both arms.

The fresh sample and deliberately selected known regressions do not establish general inferiority of a structured working state.

Fresh 12 queries: ordinary reread → structured working state yielded 6/6 → 6/6 complete supported answers, 6/6 → 6/6 correct abstentions, and 0 → 0 partial supported answers; 0 transitioned to a complete correct answer or correct abstention and 0 regressed from those outcomes.

Known 8 queries · selected regressions: ordinary reread → structured working state yielded 3/6 → 3/6 complete supported answers, 2/2 → 2/2 correct abstentions, and 3 → 3 partial supported answers; 0 transitioned to a complete correct answer or correct abstention and 0 regressed from those outcomes.

The primary comparison is ordinary reread → structured working state. The shared first answer is a lower-stage diagnostic, not the matched primary comparison. Both arms executed a query-only plan → source critique/reread → final answer and received the same originals and first answer.

The fresh set contains 12 newly source-authored queries from two unused archived sources and all 78 retained messages (50 + 28). The known set deliberately selects three prior partial answers, three prior complete answers, one confusable and one absent case from four older sources and all 95 retained messages. There are six sources and 173 messages; the 20 queries are not 20 independent sources or replications.

04 / ASSESSMENT

Separate semantic assessment from mechanical checks.

Corrected means a transition from incomplete/wrong to a correct supported answer or correct abstention; regressed is the reverse. Other partial-answer changes are not automatically called improvements. Actual AI roles assessed referents, proposal versus completion, and unsupported claims. Mechanical evidence checks are separate. Invalid source grounding prevents a fully source-bound correct answer. A budget overrun alone is not a semantic error.

06 / SOURCE-FIXED METHOD

Keep the source-fixed comparison within its scope.

Actual AI roles produced the semantic plans, critiques, answers and independent grades. Python verified source bindings, quotes, freezes, caps and counts. Original bodies were unchanged; trace, case UUID and path metadata were stripped, and reader inputs allowlisted role, text, order, timestamp and opaque IDs. Bodies may themselves identify a source, so this is not full anonymity. Meaning roles received no parent-task history and were instruction-separated on a shared host.

All messages retained in each archived source row were used; the archives are partial relative to the platform history. Source selection was fixed by privilege. This study does not measure retrieval improvements, SHIORI storage/search speed, graph or convergence effects, learning from real action outcomes, full Wake or Emotion effects.

PUBLIC SCOPE / LIMITS

Retain results and verification boundaries.

This is a descriptive comparison on a small selected sample. Fresh and known results remain separate. It does not establish general superiority, natural daily recall, personality continuity, brain reproduction or AGI.

Public material contains allowlisted aggregates, the frozen method and audit digests. It excludes originals, questions, source IDs, feature vocabulary, SQLite, private experiment code and paths. Public files support aggregate consistency checks, not source auditing or private-experiment reruns.

Code engineering checks 27/27; synthetic procedure checks 70/70. These are separate from the 60 actual AI answer outcomes. Independent audit of the public export was verified.

The final controller version ran its full 27-test unit suite. The separate 70 procedure checks comprise 57 on the retained predecessor and 13 timestamp-input cases on the final version; the intervening controller change was timestamp validation only. These are engineering and procedure checks, not memory-accuracy measurements.
