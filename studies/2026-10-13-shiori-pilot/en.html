RUN 001 / RETROSPECTIVE PILOT / v1

SHIORI: cues, paths
and retrieval.

42 real-dialogue messages were captured and indexed with 203 reviewed semantic-feature occurrences. 24 queries authored in a separate step were frozen and tested under four retrieval conditions.

2026-10-13 · Stored execution results; no engine runs while you browse.

Without a cue, there is no path to follow.

All eight paraphrase queries produced zero cues and zero candidates in every condition. Cue aggregation added five top-three target hits even without hops. One-hop traversal added one top-five hit.

  • Default preparation produced zero semantic features. The 203 feature occurrences came from source-only AI-assisted review, not automatic learning through repeated retrieval.
  • Q09–Q16 had zero cues and candidates. A zero unknown count does not mean comprehension; the parser does not enumerate every unrecognized expression.
  • Both no-target controls returned candidates. Candidate retrieval does not establish answerability. No model answers were generated.

03 / FROZEN METHOD

What was fixed for comparison.

01 Select source

One archived conversation dated 2025-02-27. Of 47 export records, two system records and three empty AI messages were excluded, leaving 21 user and 21 AI messages. One truncated AI message was retained without completion.

02 Freeze indexing

Each message became one episode. Features were reviewed from source alone and frozen before query authoring. The indexer was not given the queries.

03 Freeze queries and targets

A separate step authored eight direct, eight paraphrase, six two-clue and two no-target queries. Target sources were audited before retrieval. This was a local protocol freeze, not external preregistration.

04 Run all conditions

A 2×2 comparison: zero/one hop × best cue/cue aggregation. Aggregation sums the best contribution per cue. Main runs fixed bitmap, limit five, hub_limit 32, and no lexical fallback.

Source selection and two query/target corrections were recorded before the first retrieval; earlier versions were retained. No index or query tuning followed results. Non-overlap with an earlier 13-excerpt sample was checked using text hashes and scenes, not an independent timestamp comparison.

Preparation and recall use the same cue-parser function, but the recall lexicon is expanded by reviewed features and differs from default preparation. Role separation used AI assistance within the same team; it was not independent external blind review.

06 / VERIFICATION

What reruns actually verified.

  • All 42 captured messages matched source rereads
  • Results, scores and evidence matched across binary / tags / bitmap in all 96 query-condition cases
  • Database hash unchanged by retrieval
  • Reopening the same database returned the same results
  • Fresh Python processes and databases with hash seeds 0/17 reproduced results and metrics
  • Separate recalculation matched hit counts and MRR
  • A reproduction wrapper verified rebuilding and equality with reference results

These are internal reproduction checks using the same private frozen inputs. Aggregates are traceable from public JSON; this is not a public dataset enabling independent source or semantic-index validation.

07 / LIMITATIONS

What is shown, and what remains untested.

  • An exploratory test on one selected conversation and 24 researcher-authored queries. It does not estimate everyday conversation accuracy or statistical significance.
  • The transcript records what was said; it does not independently establish the truth of product claims or external facts in that conversation.
  • Review-dependent indexing, bounded parsing and top-five ties remain. These results do not establish personality continuity, subjective affect or a causal effect on natural recall.
  • Full LRE Wake, Emotion, automatic SHIORI integration and AI response generation were not run.
