03 / ACTUAL REVIEW

Add a source-reading decision after retrieval.

Retrieve the original query first

The existing original-first binary/network candidate retrieval remains unchanged. Original-query and recovery-semantic native routes form a shared candidate union for the four conditions.

Review query meaning against linked originals

An actual AI read each query and the candidate’s linked originals to review event, action, context, referent, role, time and mode compatibility. The review goes beyond word matching or binary-feature overlap.

Independent review and a fixed selection rule

Native rank, score, route, strict-gate decisions, query labels and query kind were hidden from the review. A separate reviewer checked the bound artifact; there were 0 pre-score repairs. Selection takes the first passing candidate in native order, without mixing scores.

This is a semantic compatibility review against source text. It does not establish world-event truth, real-world event identity or permission to adopt a candidate into an answer. The four conditions descriptively compare selection rules on this frozen sample; they do not prove general semantic understanding or causal improvement.

06 / METHOD AND ISOLATION

Freeze order and limits of isolation.

The retained selection record reports 171 archived sessions, 95 excluded and 10 eligible. Four further sessions supplied eight whole messages each. Mechanical counting decoded body strings; selection was then durably locked before semantic reading of the selected bodies. Source-only index review approved 115 features and 114 concepts before code freeze.

The query author received source material without the algorithm protocol and was instructed to use only that material. The 32 fresh queries comprise four literal, 12 paraphrase, eight absent and eight confusable queries. Query order and IDs were permuted with a seed. Roles were separated by instructions on the same host; model identity was unavailable.

The initial technical failure remains retained

The first index build failed because an input-audit alias was missing, after partial database writes. All 3 failed artifacts remain retained from before query authoring. The corrected preflight fails before writes when required input is missing. Code engineering checks passed 128/128; synthetic checks of the research procedure passed 60/60. These two sets remain separate and are not pooled with the real-dialogue evaluation.

08 / REPLAY AND LIMITS

Replay agreement and what remains unmeasured.

  • Saved actual AI outputs were replayed, with agreement checked by an independent replay. Fresh AI regeneration was not tested.
  • The fresh evaluation used 57 normal native routes plus two ablations, totaling 171 primary native search calls. Fresh preparation replay (171) and independent replay (171) calls are recorded separately. The known regression set also has separate primary (165), preparation replay (165) and independent replay (165) call counts. The final audit added a further 171 fresh-set and 165 known-regression native calls, recorded separately from the earlier replays. Replay counts are not added to evaluation-query or hit counts. “Queries searched” counts queries, not physical native calls.
  • Public JSON permits aggregate recalculation. Original conversations, query text, index vocabulary, native AI artifacts, target source IDs and private evaluation artifacts remain private; public data alone does not permit external source auditing or an engine rerun.
  • World-event truth and answer adoption are unverified. Storage/search timing, natural everyday recall, biological brain reproduction, Emotion and full Wake were not evaluated.
