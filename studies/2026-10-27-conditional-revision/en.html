STUDY / CONTROLLED CONDITIONAL REVISION / v1

When the format changes,
what changes and what stays?

We moved previously public data under payload and replayed the saved reading operations. An actual AI chose a new reading method while retaining the old method for the original format. This deliberately engineered surface-schema change tests conditional compatibility, not a natural outage, belief revision or concept learning.

2026-10-27 · Stored execution record. Browsing runs neither an AI nor the execution engine.

01 / QUESTION AND FINDING

Separate compatibility repair from revising one’s own judgment.

The primary comparison is identical raw observations → the same observations plus an AI conditional review. Both arms receive old goals/actions, actual legacy/wrapped results, schema observations, AI repairs and their actual results. Only review access is added; this is not feedback versus no feedback.

The same three saved actions were accepted 3/3 on legacy files and 0/3 after the declared wrapping change. Newly chosen AI repairs were accepted 3/3.

On the same six later items, raw observations → the same observations plus review corrected 0 outcomes and regressed 0. These are three new objectives executed in two formats, not six independent objectives.

On this sample, added review did not change which items were accepted.

All three actual review entries are classified as confirmation; conditional_update is zero. Repairing a saved external operation is distinct from revising one's own mistaken judgment. The observed classifications are retained.

02 / DECLARED FORMAT CHANGE

Declare the changed condition and preserved original.

legacy_root

Unchanged complete public-file copy

→

artifact-container.v2

payload contains the same parsed original

The declared transformation has only schema_version and payload. Payload types and values equal the original, whose raw bytes remain unchanged. The test deliberately checks whether a valid legacy path fails in the new format. It is not a naturally occurring outage or a new dialogue episode.

Actors do not receive full current JSON. They receive source handles and actual-file schema observations: keys/array order remain, scalars become type markers, only condition id strings remain, and per_query/provenance omissions are explicit. Both arms receive identical observations. Format descriptions and legacy-preservation instructions are supplied; appropriate conditional branching is not spontaneous conceptual learning.

03 / ROLES AND REAL EXECUTION

Distinguish choice, execution and post-outcome review.

  1. Execute three saved operations once per format and retain all six results.
  2. One fresh AI context chooses three repairs and predictions, frozen before execution.
  3. Execute all three repairs and return only actual results to the same repair context.
  4. That same context records three conditional-review entries; retain its actual classifications.
  5. Two other fresh contexts choose operations for the same six frozen tasks; freeze all 12 before feedback.

The 21 execution items are six saved replays + three new AI repairs + 12 later actions, not 21 fresh AI decisions or provider requests. Saved actions came from a separate earlier context; only current repair choice and post-outcome review share one new context across two turns. Repair/review and later-operation roles use three contexts and four turns, excluding task authors, reviewers and auditors. Provider request counts and continuous model identity are unverified.

Later order is F01–F06 in both arms; dispatch is raw observations, then added review. Order, provider and time effects are uncontrolled. There are no semantic retries, post-score task/gold changes or failed-item exclusions.

07 / LIMITS

Keep compatibility observations within their scope.

This is a descriptive engineered task over three public source families and three new objectives in two formats. Validation mechanically compares types and values; code does not grade natural-language understanding or learning. Legacy failures are retained separately, but incorrect output alone cannot establish subjective overgeneralization.

Original values were previously public, so prior exposure or training cannot be excluded. This is an artificial interface restricted to schema observations and handles. Roles shared a host with instruction separation, not OS isolation or authenticated provider identity. Natural recall, spontaneous concept acquisition, model-weight learning, native ChatGPT, full LRE Wake, SHIORI graph/binary speed, Emotion, biological brains, AGI and consciousness were not tested.
